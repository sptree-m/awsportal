スクリプトの実行方法
  1. ZIPを展開し、証明書・設定・スクリプトを同じフォルダーに置きます。
  2. 下のコマンドの 管理者から受領したSHA256 を置き換え、設定内容を確認します。
  3. Windowsは管理者としてPowerShellを開き -Apply を追加します。macOS/Linuxはsudoで実行し --apply を追加します。
  4. ブラウザーを再起動し、指定されたHTTPSのホスト名で接続します。

Windows（PowerShell 5.1以降）：

.\setup-windows.ps1 -ExpectedFingerprint 管理者から受領したSHA256

macOS / Linux（Python 3・openssl）：

python3 setup-unix.py --expected-fingerprint 管理者から受領したSHA256

LinuxはUbuntu/DebianとRHEL/FedoraのシステムCAストアに対応します。hostsの既存別名を保持し、変更前のバックアップを作ります。端末のスクリプト実行ポリシーは管理者の指定に従ってください。
