# v2.1.3

## 変更

- [本番環境立ち上げマニュアル](../deployment/production/README.md)を追加。既存VPC・Subnet・SG・IAM・AMI・KMS等の制約、所有権と変更権限を確認し、CloudFormation変更セット、Portal・DCV導入、MacのCA・hosts、受入、バックアップ復旧までを案内する。
- 指定値・所有者・変更可能範囲・証跡を記録する32項目の制約確認シートを追加。
- 公開IPv4で始める全新規基盤のCloudFormation例を追加。Portal/DCVのEC2、暗号化EBS、EIP、ネットワークとIAMを定義する。既存リソース利用への切替、アプリ、TLS、バックアップ、監視の完成設定は含まない。
- README・文書目次から本番手順へ誘導し、クイック導入の配布物バージョンをv2.1.3へ更新。マニュアル・シート・テンプレートをARM64配布物へ同梱する。
- 必須テストに本番基盤テンプレートのCloudFormation lintを追加する。

Portal・管理CLI・DCV Agentのアプリケーションコードと認証仕様は変更しない。

## 更新・受入

既存環境では本リリースを理由に基盤を作り直さない。既存リソースを指定されている場合、付属の全新規テンプレートをそのまま適用せず、制約確認シートと実設定を照合して構成を調整する。

新規導入ではPortal・管理CLI・DCV関連ファイルを同じv2.1.3配布物にそろえ、公開チェックサムとSHA-256を照合する。全新規例のEC2・EBS・public IPv4には料金が発生し、既定の公開範囲はIPv4のTCP/443・8443、単一AZである。

既存Portalの更新はサービス停止・DBと元のTOTP暗号鍵の別保管・設定と旧資材のバックアップを行い、[クイック導入](../deployment/quickstart.md)と[v2.1.2の更新手順](v2.1.2.md)に従う。更新後は信頼済みHTTPS、管理者認証、操作単位の本人確認、DCV接続を確認する。

文書・テンプレートの検証とAWS実機の受入は別である。本リリースの文書追加は、対象AWSアカウントへの適用、Macでのログイン・DCV画面操作、バックアップ復旧の成功を示さない。本番運用開始前にマニュアルの受入・復旧・運用引継ぎを実施する。
